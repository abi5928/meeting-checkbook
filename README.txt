만남 체크북 v22 (iPhone 받아쓰기 최적화)

v21의 체크/기록/관리/휴지통/명단, 관계·시간, 메모, Excel 기능을 유지합니다.

주요 변경
- PC/Android: 기존 웹 음성인식을 그대로 사용합니다.
- iPhone/iPad Safari 및 홈 화면 앱: Web Speech API를 호출하지 않고 앱의 🎙️ 버튼으로 이름 입력창을 바로 엽니다.
- 입력창에 자동 포커스하여 iOS 키보드가 나타나도록 하고, 키보드 🎤 받아쓰기로 입력한 이름을 자동 검색/체크합니다.
- 받아쓰기 입력은 서버로 전송하지 않으며 기존 로컬 저장 원칙을 유지합니다.
- 서비스워커 캐시 버전을 v22로 변경했습니다.

주의
iOS 웹앱에서는 웹페이지가 시스템 키보드의 받아쓰기 🎤 버튼을 직접 강제로 실행할 수 없습니다. 따라서 사용자는 앱의 🎙️ 버튼을 누른 뒤 키보드의 🎤을 한 번 눌러야 합니다.
