v2.10 보안 통합 테스트 v3

이번 수정:
- 기존/구버전 보안 설정 정보가 남아 있어도 최초 보안 설정을 한 번 거치도록 수정
- 보안 설정 완료 여부를 setupComplete로 명확히 구분
- 비밀번호 사용 안 함을 선택한 경우에는 이후 실행에서 설정창이 반복되지 않음
- 기존 v2.10 데이터는 가능한 경우 그대로 불러온 뒤 보안 설정 선택 가능

테스트:
1. 휴대폰에서 최초 접속
2. 보안 설정 화면이 나타나는지 확인
3. '비밀번호 사용 안 함' 선택
4. 앱 정상 진입 확인
5. 관리 → 앱 잠금 → 비밀번호 사용
6. 4자리 비밀번호 설정 및 재실행 확인
